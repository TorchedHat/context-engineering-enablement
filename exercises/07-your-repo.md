# 07 · Your repo

**Concept:** everything you configure is paid on every turn. Prune for the
recurring cost.

1. In a new terminal, `cd` into a repo you actually work in.
2. Start the agent. Run `/context` (Codex: `/status`).
3. Find the biggest block you did not expect: an MCP server you never use, a
   CLAUDE.md that is really a README, a plugin you forgot about.
4. Post it on the Miro board: *"I'm paying ___ tokens per turn for ___."*

That is one thing to prune tomorrow.
