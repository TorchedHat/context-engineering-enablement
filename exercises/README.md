# Exercises

Seven exercises in managing context and memory inside a coding session: how the
request grows, what compaction keeps, and where to put what has to last. Each
step is something to paste, with the expected result under it. Do them in
order; each one uses what the last one left behind.

**Working in a group:** one person from the team runs it and shares their
screen. The session, and the memory it writes, live on that machine.

| Exercise | What you'll see |
|---|---|
| [00 · The mental model](00-mental-model.md) | what the agent actually gets when you hit Enter, and the four ways that goes wrong |
| [01 · Feel the meter](01-feel-the-meter.md) | watch the request grow with every file and command, and learn to let less in |
| [02 · Watch it break](02-watch-it-break.md) | say one thing, have it print thirty, compact, see which one survives, then tell it what to keep |
| [03 · Make it survive](03-make-it-survive.md) | put the facts in a file so compaction can't touch them |
| [04 · Make it remember](04-make-it-remember.md) | tell the agent about yourself, find the file it wrote, break it, fix it by hand |
| [05 · Make it answer your way](05-make-it-answer-your-way.md) | set a reply format once and have every future session follow it |
| [06 · The handoff](06-the-handoff.md) | plan something, write a handoff file, quit, and pick it back up from the file |
